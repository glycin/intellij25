# IDE Survivors

A survivors-style game built as an IntelliJ IDEA plugin to celebrate IntelliJ's 25th anniversary.

## About

IDE Survivors is a roguelite arcade game created for JetBrains s.r.o. as part of their 25th anniversary celebration of IntelliJ IDEA. 
Battle waves of enemies, collect jetbrains coins, and unlock powerful upgrades to survive! All inside your IDE.

## How to Play

- **Move** with `W` `A` `S` `D` keys
- **Defeat enemies** and collect the coins they drop
- **Level up** by filling the experience bar and choose from available upgrades
- **Mix and match** upgrades to create powerful synergies
- **Press `ESC`** during gameplay to pause
- **Survive**!

## Getting Started

### Prerequisites

- IntelliJ IDEA (Community or Ultimate)
- JDK 17 or higher

### Running the Game

1. Clone this repository
2. Open the project in IntelliJ IDEA
3. Run the **'Run Plugin'** configuration
4. The game will launch in a separate IDE instance

## Development

This plugin is built using:
- Kotlin
- IntelliJ Platform SDK
- Java Swing for rendering
